# Report UI

TanStack + Tailwind dashboard for exploring deterministic crawl output.

## Run

```bash
bun install
bun run dev
```

## Data Input

This app expects a `flow_bundle.json` payload generated by the Python crawler.

You can load data in two ways:

1. Place `flow_bundle.json` in `report-ui/public/` for auto-load at startup.
2. Use the **Load Bundle JSON** file picker in the UI.

Main UI areas:

- `Transitions` for readable flow edges.
- `Generated Test Cases` for derived positive/negative scenarios.
- `Discovered Pages` for unique crawl states (with optional technical IDs).

## Build

```bash
bun run build
```
